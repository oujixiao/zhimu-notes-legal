## 1. 我们收集哪些数据

本扩展默认将数据保存在您的浏览器本地（`chrome.storage.local` 与 IndexedDB），包括：

- 视频 URL、标题、平台、时长
- 您创建的笔记文本与时间戳
- 截图（若使用截图功能）
- AI 摘要结果（若生成）
- 设置项（如 API Key、OCR 引擎 / 代理地址）
- 本机使用统计（如截图、导出次数），仅存本机，不上报到开发者服务器

在 Bilibili / YouTube 视频页，扩展会注入内容脚本，读取播放进度、页面标题等公开页面信息，用于笔记关联、时间戳跳转与截帧；**不会因此上传完整视频文件**。

仅在您主动使用云端能力时，才会向第三方发送数据。**不会上传完整视频文件。** 截帧优先从播放器画面截取；若因跨域等原因失败，可能降级为捕获当前标签页可见区域（可能包含播放器以外的页面内容），请避免在含敏感信息的页面使用截图。

| 功能 | 可能上传的数据 |
|------|----------------|
| AI 摘要 | 视频 URL、字幕/逐字稿、笔记文本、平台章节信息 → 您配置的 LLM API |
| OCR 通道 A | 截图发送至您配置的 OCR 代理（默认本机 `http://127.0.0.1:8787`）。代理由您自行启动或部署；若代理配置了百度智能云密钥，再转发至百度文字识别。开发者默认不经手、不落盘您的截图。 |
| OCR 通道 B / 文本优化 | 截图或 OCR 文本直连您配置的第三方 API（如通义、智谱等） |

## 2. 第三方处理方

- 视频站点：Bilibili、YouTube（仅在对应页面运行，用于读进度与截帧，不向其额外上传笔记）
- 您自行配置的 LLM / 多模态 API，预设可选包括 DeepSeek、阿里云通义 DashScope、Moonshot、智谱 BigModel，也可填写兼容的自定义 HTTPS 地址
- 通道 A：百度智能云文字识别（经您自建的 OCR 代理转发时适用），并受百度相关服务条款与隐私政策约束
- 可选：本机或自建 OCR 代理（如 `localhost:8787`），由您运行；截图先到该代理，再按代理配置转发

我们不运营强制账号体系，也不在产品服务器上持久化您的笔记正文。第三方如何处理数据，以其各自隐私政策为准。

## 3. API Key

Key 仅保存在本机浏览器；直连模式下仍可能被本机恶意软件或其他扩展读取。建议在厂商控制台设置每日用量上限并定期轮换；请勿将 API Key 提交到代码仓库或发给他人。

## 4. 数据保留与删除

- 本地数据随扩展存储保留，直到您清除或卸载扩展
- 设置页提供「清除所有数据」
- 已发送至第三方的数据，保留与删除按其服务规则执行

本扩展不面向儿童设计，也不会主动收集儿童的个人信息。若您认为有相关数据需处理，请通过下方联系方式告知。
